# 桜町三丁目 · 星野マート 24H

基于用户提供的 `24h (4).html` 完善，保留日漫三渲二、夜樱公园、住宅街区和便利店室内。原始下载文件未修改，项目内也保留了 `original.html`。

## 打开

双击 `index.html`，使用支持 WebGL 2 的现代浏览器。它包含打包后的 Three.js、OrbitControls、Reflector 和 GSAP，不依赖 CDN 或联网加载。可以单独复制这一个 HTML 到其他电脑。

## 这一轮增加和调整

- 自行车：车篮、辐条、脚撑；窗边避雨的小猫、纸箱、水碗；侧门补货箱、标签；入口盆栽和咖啡小牌。
- 七个街角故事标记、配套的可键盘操作按钮与特写镜头。
- 完整底座全景，按屏幕比例适配取景；公园镜头拉高，避免贴着树冠移动。
- 保留蓝色雨夜，黄昏恢复原始紫色与金黄色渐变及紫色环境光；胡桃木纹底座和黄铜固定件。
- 黄昏渐变适配低机位，保持紫色上空、金黄色下缘；天空按正确输出色域显示，反射视口同步更新，快速切换雪天时会取消未完成的天空过渡。
- 开场自由观察；底部演示栏、字幕和巡游入口已移除。
- 修复手动开关门被定时器覆盖；新的相机操作会取消旧镜头动作。
- 可切换无降水、雨天、雪天；雪天有飘雪、冷色天空与屋顶和地面覆雪。雨雪共用粒子缓冲区，按选择单独渲染。
- 降水密度滑块、保存当前画面、手机布局、隐藏页面时暂停画面更新。
- 樱花树重做：移除扁平盘状树冠和交叉花朵贴片，改用分叉枝干与密集的立体五瓣花；补足盛放期的树冠体积，每棵树使用不同的枝形与花簇分布。
- 住宅重做：右前方是昭和绿瓦独栋，有凸窗、晾衣阳台、门柱信箱、半开木门、石板步道和花木小院；西侧是障子、縁側和水钵石庭的木造住宅。古书店移到右后方保留，公寓、茶屋和现代住宅补齐侧窗、墙面层次、落水管与生活细节。
- 住宅灯光：更柔和的室内窗帘贴图与分层窗框；窗格投影、门灯光晕、局部暖光与轻量体积光束。二楼光束收在阳台或屋檐表面，住宅光效可独立调节，并随白昼氛围减弱。
- 旧住宅灯光统一：茶屋、公寓、现代住宅和古书店与两个新院子共用同一套灯光参数；48 处亮窗全部接入投影与柔光束，旧黄色平面与公寓走廊灯也已替换。
- 性能：按材质和空间区域合并静态建筑、墨线和加法光效；远处樱花保留全部花朵数量，使用更简单的花瓣几何；冻结静态物体的矩阵计算，保留门、屋顶、车流、天气和树冠动画。固定渲染设置，无画质选项和自动降档。
- 交通标线直接由柏油路材质绘制并按屏幕导数抗锯齿，移除低角度下与路面争抢深度的薄盒子。门头改用符合实体比例的高清贴图（正面 4096×320、侧面 1536×384）、更大的主文字及各向异性过滤。

## 操作

- 拖动旋转；右键拖动平移；滚轮靠近或远离。
- 点击故事按钮或圆形数字标记，直接进入对应特写；再次点击同一故事返回微缩盒景。机位按钮也支持再次点击返回。
- 左上角「场景工作台」展开天气、机位和拆解控制。
- `R`：完整盒景；`H`：折叠/展开工作台；`Esc`：关闭细节卡。
- 默认采用参考截图约 22° 的低俯视角和更近的全景构图，宽屏默认相机距离 92，并按窄屏取景需求适配。开启自动环绕：便利店正面约 3.5°/秒，侧面约 4.375°/秒，背面最高 5.25°/秒，连续平滑变速。拖动或缩放时暂停，操作结束 2.5 秒后平滑恢复；选定特写后保留 8 秒观察时间。顶部「自动环绕」可随时关闭或开启。
- 「保存画面」导出当前纯模型 PNG，不包含控制面板。
- 点击 `06` 看绿瓦小院，点击 `07` 看木造縁側；工作台中也有四栋旧住宅的窗光机位与「住宅窗光与柔光束」滑块。
- 「天气与降水」中选择雪天。渲染统一使用原有的像素比上限 1.5、512×512 实时反射和阴影，最高 60 FPS；没有画质选择，也不根据帧率降低分辨率或关闭阴影。
- 雪天包含屋顶及地面覆雪、路沿雪堆、轮胎压出的车辙和戴帽子的雪人。点击「☃️ 路边雪人与积雪」进入近景；雪花固定在街区的三维空间中，独立随机分布并按距离缩放，不跟随相机，下落和横向飘动较前版加快 50%。雪景使用合并几何和共享粒子缓冲，切回雨天恢复湿路反射。
- 标题取消模糊光晕；白天和雪天使用深色字与浅色底衬，雨夜和黄昏使用浅色字与深色底衬。
- 如果已经打开本地 HTML，修改后按 Ctrl+R 刷新；本地文件不会自动热更新。

## 继续修改

`scene.js` 是可编辑的场景源码，`shell.html` 是页面和界面样式；修改后运行 `npm run build`，生成新的离线 `index.html`。打包脚本会检查最终内嵌 JavaScript 的语法。

`prepare.py` 是本轮从原文件迁移的可复现脚本，读取 `original.html`、`details.js`、`sakura.js` 和 `enhancements.css`，重新生成 `scene.js`、`shell.html`。它会覆盖这两个生成文件，因此在直接修改场景源码后不要运行迁移脚本。

住宅单独放在 `residential-core.js`（窗户、材质和通用小物）、`courtyard-house.js`（绿瓦庭院）、`traditional-house.js`（木造石庭）、`residential-finishing.js`（其余立面与灯光）中，迁移脚本也会读取这些文件。光束采用适配三渲二的透明体积网格与投影贴图，不是物理路径追踪雾。

`weather.js` 管理雨雪与覆雪几何；`performance.js` 管理静态合批、花瓣远近细节、静态矩阵冻结和帧率限制。迁移脚本会一并读取它们。

`road-paint.js` 管理同表面交通标线和雨雪光效绘制顺序；`store-signage.js` 管理正面、侧面门头的字体排版与贴图过滤。这两者也由迁移脚本读取。

路沿积雪采用连续网格，横断面从人行道平缓过渡到路面；沿道路改变宽度、高度与边缘，并保留人行横道缺口。已移除排列的半椭球雪块，雪脊与地面合为同一批静态几何。

`scene-space.js` 提供世界空间雪花模拟与灯光三角形边界裁切。住宅和便利店光斑在合批前裁切，并在底座边缘渐隐。运行 `node verify-scene-space.mjs` 检查边缘、旋转接收面、UV 插值与雪花连续分布及视角独立性。

`orbit-motion.js` 管理闲置环绕状态、参考视角配置及角速度，`auto-orbit.js` 负责 Three.js 相机所有权与控件；运行 `node verify-orbit.mjs` 检查速度范围、参考视角、暂停恢复、中断衔接和帧率独立性。

锁定依赖：Three.js 0.170.0、GSAP 3.12.5、esbuild 0.25.12。许可文本保存在 `THIRD_PARTY_NOTICES.txt`。
